    1. Guía de conceptos clave

    1.1 Fórmulas

    Anclas válidas $$\text{ancla} \in [\,t_{min}+v_{obs}-1,\ t_{max}-v_{des}\,]$$
    Renglones de la TAD = nº de anclas × nº de unidades muestrales.
    Ventanas para un ancla $$X:\ t \in (\text{ancla}-v_{obs},\ \text{ancla}],\qquad y:\ t = \text{ancla}+v_{des}$$
    Porcentaje de ausentes $$\%\text{nulos} = 1 - \frac{\text{count}}{n}$$
    Estadístico KS $$D = \max_x \lvert F_{orig}(x) - F_{imp}(x)\rvert,\quad D>0.1 \Rightarrow \text{rota}$$
    Máxima distancia entre las dos distribuciones acumuladas.
    RS_Ratio (VarClus) $$\text{RS\_Ratio} = \frac{1-\text{RS\_Own}}{1-\text{RS\_NC}}\quad(\text{bajo es mejor})$$
    Z-score y Min-Max $$z = \frac{x-\bar x}{s},\qquad x' = \frac{x-\min}{\max-\min}$$
    StandardScaler usa la desviación poblacional (ddof = 0).
    WoE e IV $$\text{WoE}_i = \ln\frac{\%\text{no evento}_i}{\%\text{evento}_i},\quad \text{IV} = \sum_i(\%\text{ne}_i-\%\text{e}_i)\,\text{WoE}_i$$
    Momios y logística $$\ln\frac{p}{1-p} = \beta_0+\sum\beta_i x_i,\qquad p = \frac{1}{1+e^{-(\beta_0+\sum\beta_i x_i)}}$$
    Subir 1 en \(x_i\) multiplica los momios por \(e^{\beta_i}\).
    Escala del score $$\text{Factor} = \frac{\text{PDO}}{\ln 2},\quad \text{Offset} = \text{Score}-\text{Factor}\ln(\text{odds}),\quad \text{Score} = \text{Offset}+\text{Factor}\ln(\text{momios})$$
    Puntos por atributo (diapositiva) $$\text{Puntos} = \Big(-\text{WoE}\cdot\beta+\frac{\alpha}{n}\Big)\text{Factor}+\frac{\text{Offset}}{n}$$
    Si la logística modela P(malo), el término del intercepto lleva \(-\alpha/n\) (ver Módulo 1, 11.5).
    Métricas de clasificación $$\text{Acc}=\frac{TP+TN}{N},\ \text{Prec}=\frac{TP}{TP+FP},\ \text{Rec}=\frac{TP}{TP+FN},\ \text{Esp}=\frac{TN}{TN+FP}$$ $$F_1 = \frac{2\,\text{Prec}\cdot\text{Rec}}{\text{Prec}+\text{Rec}}$$
    Regresión: MAE $$\text{MAE} = \frac{1}{n}\sum_i \lvert y_i-\hat y_i\rvert$$
    Ecobici: MAE = 27,006 afluencias.

    2. Ejercicios resueltos

    Intenta cada uno antes de abrir la solución. Los resultados se comprobaron ejecutándolos con Python.

    E1. Un archivo tiene 390 estaciones observadas en t = 1…700. Con vobs = 20 y vdes = 1, ¿cuántos renglones tendrá la TAD antes de limpiar? ¿Y con 36 periodos, vobs = 12, vdes = 3, por unidad muestral?

    Anclas: de \(1+20-1 = 20\) a \(700-1 = 699\) → 680 anclas. Renglones: \(680\times390 = \mathbf{265{,}200}\) (lo mismo que en el notebook; después se quitan 123 con \(y\) vacía). Segundo caso: de \(12\) a \(36-3 = 33\) → 22 renglones por unidad muestral.

    E2. Para la serie [5, 7, 7, 6, 9, 10] calcula sum_inc, sum_dec, media_inc, delta_mean, max_racha_inc y media_racha_dec con las funciones de la sesión 8.

    Cambios: +2, 0, −1, +3, +1. Cadena de subidas "10011", de bajadas "00100".

    • sum_inc = 3, sum_dec = 1 (el empate 7→7 no cuenta en ninguna).
    • media_inc = 3/5 = 0.6; delta_mean = (2+0−1+3+1)/5 = 1.0.
    • "10011".split("0") = ["1", "", "11"] → longitudes [1, 0, 2] → max_racha_inc = 2.
    • "00100".split("0") = ["", "", "1", "", ""] → [0, 0, 1, 0, 0] → media_racha_dec = 0.2. Las cadenas vacías bajan el promedio: por eso en el ejemplo de la clase media_racha_dec = 0.33.
    E3. Estandariza [2, 4, 6, 8, 10] con z-score y con Min-Max. ¿Qué desviación usa StandardScaler?

    Media = 6. StandardScaler usa la desviación poblacional: \(\sqrt{(16+4+0+4+16)/5} = \sqrt8 = 2.828\) (con ddof = 1 sería 3.162). z = [−1.414, −0.707, 0, 0.707, 1.414]. Min-Max: (x − 2)/8 = [0, 0.25, 0.5, 0.75, 1].

    E4. Calcula a mano el WoE de cada bin y el IV. Bin A: 30 eventos, 170 no eventos. Bin B: 70 eventos, 730 no eventos.

    Totales: 100 eventos y 900 no eventos.

    • A: %e = 0.30, %ne = 170/900 = 0.1889 → WoE = ln(0.1889/0.30) = −0.4626; IVA = (0.1889 − 0.30)(−0.4626) = 0.0514.
    • B: %e = 0.70, %ne = 730/900 = 0.8111 → WoE = ln(0.8111/0.70) = 0.1473; IVB = (0.8111 − 0.70)(0.1473) = 0.0164.
    • IV = 0.0678 → poder predictivo bajo. El bin A es más riesgoso (WoE negativo).
    E5. VarClus dio para un mismo cluster: A (RS_Own 0.90, RS_NC 0.20), B (0.95, 0.50), C (0.80, 0.10). ¿Qué variable se queda?

    RS_Ratio: A = 0.10/0.80 = 0.125; B = 0.05/0.50 = 0.100; C = 0.20/0.90 = 0.222. Se queda B (id == 1). C tiene el RS_NC más bajo, pero su RS_Own también es el más bajo: lo que decide es el cociente.

    E6. Dos muestras: original [1, 2, 3, 4] e imputada [3, 4, 5, 6]. ¿Cuánto vale el estadístico KS y la variable está "rota"?

    Distribuciones acumuladas: en x = 2, Forig = 0.50 y Fimp = 0 → diferencia 0.5; en x = 3: 0.75 vs 0.25; en x = 4: 1.0 vs 0.5. Máximo = 0.5 (ks_2samp da lo mismo). 0.5 > 0.1 → rota.

    E7. Una logística da logit = −2 + 0.8·x. Para x = 1.5, ¿cuáles son los momios y la probabilidad del evento? ¿Por cuánto se multiplican los momios si x sube 1?

    logit = −2 + 1.2 = −0.8. Momios = e−0.8 = 0.449. p = 1/(1 + e0.8) = 0.310 (o momios/(1 + momios) = 0.449/1.449). Si x sube 1, los momios se multiplican por e0.8 = 2.23.

    E8. Escala de score con PDO = 20, Score = 600 para momios 50:1. Calcula Factor, Offset y los scores para momios 100:1, 25:1 y 1:1.

    Factor = 20/ln 2 = 28.854. Offset = 600 − 28.854·ln 50 = 600 − 112.88 = 487.12. Score = Offset + Factor·ln(momios): 100:1 → 620; 25:1 → 580; 1:1 → ln 1 = 0 → 487.12 (el Offset es el score de momios 1:1). Cada vez que los momios se duplican el score sube 20.

    E9. Matriz de confusión [[80, 20], [10, 40]] (formato de sklearn). Calcula accuracy, precisión, recall, especificidad y F1.

    TN = 80, FP = 20, FN = 10, TP = 40 (N = 150). Accuracy = 120/150 = 0.80. Precisión = 40/60 = 0.667. Recall = 40/50 = 0.80. Especificidad = 80/100 = 0.80. F1 = 2(0.667·0.8)/(1.467) = 0.727.

    E10. En la validación de churn hay 1,806 clientes, 492 de ellos con fuga. El modelo tuvo accuracy 0.806. ¿Qué accuracy tendría un modelo que dice "nadie se va"?

    Acierta los 1,806 − 492 = 1,314 que se quedan: 1,314/1,806 = 0.728. El modelo real solo gana 8 puntos de accuracy, pero su recall de 0.547 dice lo importante: detecta a poco más de la mitad de quienes se van.

    E11. Una TAD tiene tres categóricas con 3, 4 y 10 categorías. ¿Cuántas columnas dummy se crean con y sin drop_first? ¿Cuántas columnas WoE?

    Sin drop_first: 3 + 4 + 10 = 17. Con drop_first: 2 + 3 + 9 = 14. Con WoE: 3 (una por variable). Esa es la "reducción de dimensionalidad" que la diapositiva atribuye al WoE.

    E12. Frecuencias de una variable: A 47 %, B 30 %, C 16 %, D 4 %, E 2 % y 1 % de valores nulos (en total, 100 %). Aplica el tratamiento del curso (umbral 3 %).

    1) Nulos → "Sin categoría" (1 %). 2) Categorías con menos de 3 %: E (2 %) y "Sin categoría" (1 %) → se juntan en "Otros" (3 %). Resultado: A, B, C, D, Otros. Si después de normalizar quedara una sola categoría, la variable sería unaria y se eliminaría.

    5. Preguntas abiertas tipo examen

    Explica qué es la TAD, cómo se construye con ventanas de tiempo y qué es la unidad muestral, usando el ejemplo de Ecobici.

    La TAD es la tabla con la que aprende el modelo: matriz de predictoras \(X\) y vector solución \(y\), un renglón por unidad muestral. En Ecobici los datos vienen por estación y periodo, y la pregunta es la afluencia futura de cada estación, así que la unidad muestral es estación + ancla. Para cada ancla se toman los 20 periodos anteriores (ventana de observación) y se calculan 21 variables (suma, mínimo, máximo, media, desviación, subidas, bajadas, deltas, rachas); \(y\) es la afluencia en ancla + 1 (ventana de desempeño). Se repite para las anclas 20 a 699 y se apilan: 265,200 renglones. Ninguna variable puede usar información posterior al ancla.

    Describe en orden los pasos de limpieza de la TAD y qué decide cada uno.

    1) % de nulos por variable. 2) Si son pocos se eliminan registros; si no, se imputa (media/mediana; fit calcula, transform rellena). 3) KS entre la variable original y la imputada: KS > 0.1 → rota, fuera. 4) VarianceThreshold quita variables casi constantes (umbral según escala). 5) Extremos: registros fuera de p1–p99 en alguna variable se eliminan, después de pegar la unidad muestral. 6) Análisis bivariado (correlación, pairplot). 7) VarClus para multicolinealidad: una variable por cluster (id == 1 por RS_Ratio).

    ¿Qué son WoE e IV, cómo se calculan para una variable continua y cómo se usan para seleccionar variables?

    WoEi = ln(%no eventoi/%eventoi) mide si un bin tiene más o menos riesgo que el promedio. Para continuas: discretizar (en la sesión 9, 2 a 6 cortes por cuantiles), contar eventos y no eventos por bin y sacar el logaritmo del cociente de proporciones. IV = Σ(%ne − %e)·WoE resume el poder predictivo: <0.02 no ayuda, 0.02–0.1 bajo, 0.1–0.3 regular, 0.3–0.5 fuerte, ≥0.5 sobrepredictiva. Se elige el número de cortes de mayor IV por variable, se filtra (0.1 < IV < 0.8 en el notebook) y las seleccionadas se transforman a WoE con el mapa aprendido en entrenamiento. Un IV infinito o enorme indica que la variable puede estar dando la respuesta.

    Compara PCA y t-SNE, y WoE y variables dummy: ¿cuándo usarías cada uno?

    PCA: lineal, combinaciones de máxima varianza, conserva la estructura global y puede transformar datos nuevos → para reducir variables antes de un modelo (estandarizando antes). t-SNE: no lineal, excelente para ver clústeres en 2D/3D, pero costoso, depende del perplexity y no conserva la estructura global → solo para explorar. WoE: una columna por variable, captura la relación con el objetivo, ideal para logística y scoring, pero menos interpretable y requiere discretizar. Dummies: simples e interpretables, pero explotan la dimensión con muchas categorías y causan multicolinealidad si no se quita una columna.

    ¿Qué es data leakage? Da tres ejemplos del material del módulo.

    Es usar en el entrenamiento información que no estaría disponible al momento de predecir; el modelo se ve excelente en validación y falla en producción. Ejemplos: 1) variables calculadas con datos posteriores al ancla ("ojo con variables futuras"); 2) Churn_Label, Churn_Score, Churn_Reason y Churn_Category, que se derivan de la fuga; 3) Customer_Status, que incluye "Churned" y tiene IV infinito. Una forma más sutil es calcular el WoE (o el escalamiento) con los datos de validación, por eso se aprende solo con el 70 %.

    Explica cómo pasar de una regresión logística a una scorecard y qué papel juegan PDO, Factor y Offset.

    La logística (con variables WoE) da un logit lineal: ln(momios) = α + Σβ·WoE. El score se define como una transformación lineal de ln(momios bueno:malo): Score = Offset + Factor·ln(momios). El analista fija la escala con PDO (puntos para duplicar los momios) → Factor = PDO/ln 2, y con un punto de referencia (score para unos momios) → Offset = Score − Factor·ln(odds). El logit se reparte entre las n variables para dar puntos a cada atributo: (−WoE·β + α/n)·Factor + Offset/n. El score del cliente es la suma de los puntos de sus atributos. El Offset desplaza la distribución de scores y el Factor la estira.

    ¿Por qué el accuracy no basta para evaluar el modelo de churn? ¿Qué métricas usarías?

    La clase positiva es 27 %, así que decir "nadie se va" ya da 72.8 % de accuracy; el 0.806 del modelo no dice cuántos de los que se van detecta. La matriz [[1186, 128], [223, 269]] da recall = 0.547 (detecta 55 % de las fugas) y precisión = 0.678. Se usan AUC (con probabilidades: 0.854), recall, precisión, F1 y la matriz de confusión; además, el corte 0.5 se puede mover según el costo de cada error.

    Diferencia entre OLTP y OLAP y cómo se construyó un cubo en la sesión 10.

    OLTP registra transacciones del día a día con detalle (cada medición por estación y hora), con muchas inserciones pequeñas y un modelo normalizado. OLAP sirve para analizar: datos agregados e históricos organizados en hechos (medidas: los contaminantes) y dimensiones (tiempo, ubicación), con operaciones roll-up, drill-down, slice, dice y pivot. En la sesión 10 se derivaron 13 dimensiones de tiempo de la fecha y la zona por cuadrantes respecto a la latitud/longitud promedio; cada cubo es un groupby por dimensión con agregados (media, etc.), apilados con concat y guardados en CSV/Excel.
