    Entrenamiento / validaciónLos datos se parten (70 % / 30 % en los notebooks, train_test_split). El modelo aprende con uno y se mide con el otro, que nunca vio.

    Data leakage (fuga de información)Usar en \(X\) algo que no se conocería al momento de predecir: variables futuras ("ojo con variables futuras") o que "dan la respuesta" (Customer_Status).

    ¿Qué aprende el modelo? Una función \(y = h(\mathcal{X})\). Para eso se construye la TAD (Tabla Analítica de Datos): una matriz de predictoras \(X\) (características) y un vector solución \(y\) (variable objetivo). "El modelo aprende de X".

    2.1 Unidad muestral y variable objetivo

    Antes de programar hay que contestar: ¿qué información se tiene? ¿qué representan los datos? ¿qué problemática se desea resolver? En el ejemplo de Ecobici se tiene el histórico de viajes a nivel viaje, pero la pregunta es la oferta y demanda por estación. Por eso:

    • Unidad muestral → representación numérica de un objeto (aquí: la estación en un periodo).
    • Variable objetivo → resultado de una observación (aquí: la afluencia del siguiente periodo).

    En el notebook de la sesión 8 se plantean dos problemas supervisados con la misma TAD: (1) pronosticar la afluencia en t+1 → regresión y (2) clasificar si la estación será de alta afluencia (> 200,000) → clasificación.

    2.2 Ventanas de tiempo

    Se elige un ancla (un momento \(t\)). Todo lo anterior al ancla es la ventana de observación (de ahí salen las variables \(X\)); lo posterior es la ventana de desempeño (de ahí sale \(y\)). Preguntas clave: ¿cuánto tiempo debo analizar? ¿para predecir cuánto tiempo hacia adelante?

    ⚠️ Ojo con las variables futuras

    Ninguna variable de \(X\) puede usar información posterior al ancla. Si se cuela (data leakage), el modelo se ve espectacular en entrenamiento y falla en producción.

    # Módulo 1 · Ventanas de tiempo y construcción de la TAD (Tabla Analítica de Datos)
# Idea de la sesión 8 (Ecobici): con lo observado en [ancla-vobs+1, ancla] predecir t = ancla + vdes
import pandas as pd

# Afluencia de 2 estaciones durante 8 periodos (datos de juguete)
df = pd.DataFrame({
    "id_estacion": ["E1"] * 8 + ["E2"] * 8,
    "t": list(range(1, 9)) * 2,
    "afluencia": [10, 12, 15, 11, 18, 20, 19, 25,
                  50, 48, 47, 52, 40, 38, 41, 37],
})

um = ["id_estacion"]          # unidad muestral
vobs, vdes = 3, 1             # ventana de observación (3 periodos) y de desempeño (1 periodo)
t_min, t_max = df["t"].min(), df["t"].max()
anclai, anclaf = t_min + vobs - 1, t_max - vdes
print(f"Anclas posibles: de {anclai} a {anclaf}")

def sum_inc(l):               # ¿cuántas veces subió la serie?
    return sum(int(y > x) for x, y in zip(l, l[1:]))

lst_X, lst_y = [], []
for ancla in range(anclai, anclaf + 1):
    # ---- X: SOLO información del pasado (ventana de observación) ----
    obs = df[(df["t"] > ancla - vobs) & (df["t"] <= ancla)]
    aux = obs.pivot_table(index=um, values="afluencia",
                          aggfunc=["sum", "min", "max", "mean", sum_inc])
    aux.columns = [f"v_{a}_{b}" for a, b in aux.columns]
    aux.insert(0, "ancla", ancla)
    lst_X.append(aux.reset_index())
    # ---- y: el valor en el FUTURO (ventana de desempeño) ----
    fut = df[df["t"] == ancla + vdes][um + ["afluencia"]].rename(columns={"afluencia": "y"})
    fut.insert(1, "ancla", ancla)
    lst_y.append(fut)

X = pd.concat(lst_X, ignore_index=True)
y = pd.concat(lst_y, ignore_index=True)
tad = X.merge(y, on=um + ["ancla"], how="inner")
tad["y2"] = (tad["y"] > 30).astype(int)       # versión clasificación: ¿alta afluencia?
print(tad.to_string(index=False))

    # Módulo 1 · Tablas de frecuencias, groupby, merge, concat y np.where
# La tabla FA / FR / FAA / FRA es la que imprime la función freq() de la sesión 9 (churn)
import numpy as np
import pandas as pd

clientes = pd.DataFrame({
    "Customer_ID": ["C1", "C2", "C3", "C4", "C5", "C6", "C7", "C8"],
    "Contract": ["Month-to-Month", "One Year", "Month-to-Month", "Two Year",
                 "Month-to-Month", np.nan, "One Year", "Month-to-Month"],
    "Monthly_Charge": [70.0, 55.5, 99.9, 20.0, 89.0, 45.0, 60.0, 101.0],
    "Churn_Value": [1, 0, 1, 0, 1, 0, 0, 0],
})

# 1) "La falta de información también es información": el nulo se vuelve una categoría
clientes["Contract"] = clientes["Contract"].fillna("Sin categoría")

# 2) Tabla de frecuencias: absoluta, relativa y sus acumuladas
def freq(df, var):
    t = df[var].value_counts().to_frame("FA")
    t["FR"] = t["FA"] / t["FA"].sum()
    t["FAA"] = t["FA"].cumsum()
    t["FRA"] = t["FR"].cumsum()
    return t

print("Tabla de frecuencias de Contract:\n", freq(clientes, "Contract").round(3).to_string(), sep="")

# 3) groupby: tasa de fuga (media del 0/1) y cargo promedio por tipo de contrato
res = clientes.groupby("Contract").agg(clientes=("Customer_ID", "count"),
                                       tasa_fuga=("Churn_Value", "mean"),
                                       cargo_medio=("Monthly_Charge", "mean"))
print("\nTasa de fuga por contrato:\n", res.round(3).to_string(), sep="")

# 4) np.where: variable nueva con una condición (vectorizado, sin for)
clientes["cargo_alto"] = np.where(clientes["Monthly_Charge"] > 80, 1, 0)
print("\nCargo alto (> 80):", clientes["cargo_alto"].tolist())

# 5) merge: pegar otra tabla por la llave (unidad muestral)
demograficos = pd.DataFrame({"Customer_ID": ["C1", "C2", "C3", "C4", "C5", "C6", "C7", "C9"],
                             "Age": [25, 41, 33, 67, 29, 52, 38, 45]})
inner = clientes.merge(demograficos, on="Customer_ID", how="inner")
left = clientes.merge(demograficos, on="Customer_ID", how="left")
print(f"\nmerge inner: {inner.shape} | merge left: {left.shape} | "
      f"clientes sin edad tras el left: {left['Age'].isna().sum()} ({left.loc[left['Age'].isna(), 'Customer_ID'].tolist()})")

# 6) concat: apilar tablas con las mismas columnas (así se apilan las anclas en la sesión 8)
a = pd.DataFrame({"id": ["E1", "E2"], "ancla": [20, 20]})
b = pd.DataFrame({"id": ["E1", "E2"], "ancla": [21, 21]})

    7. Limpieza y análisis exploratorio de la TAD

    El orden que siguen los notebooks de las sesiones 8 y 9 (vale la pena memorizarlo):

    1. Valores ausentes: % de nulos por variable: 1 − count / len.
    2. Imputación: si son pocos, eliminar registros; si no, imputar (media/mediana) con SimpleImputer (fit calcula, transform rellena).
    3. Distribución alterada: prueba KS entre la variable original (sin nulos) y la imputada. Si KS > 0.1 la variable se considera "rota" y se descarta.
    4. Varianza: VarianceThreshold elimina variables casi constantes (sin información).
    5. Valores extremos: se marcan registros fuera de los percentiles 1 y 99 y se eliminan (¡antes, guardar la unidad muestral!).
    6. Análisis bivariado: correlaciones (heatmap, pairplot).
    7. Multicolinealidad: VarClusHi agrupa variables parecidas y se queda con una por cluster.

    Estándar (z-score) $$z = \frac{x - \bar{x}}{s}$$
    Media 0 y desviación 1. Evita que una variable domine por su escala.
    Min-Max $$x' = \frac{x - \min}{\max - \min}$$
    Valores entre 0 y 1; mantiene la proporción entre valores.

    "Ambos son buenos, depende del modelo a utilizar y la problemática". Min-Max es sensible a extremos (un solo valor enorme comprime a todos los demás).

    11. Clasificación binaria: Credit Scoring

    El credit scoring evalúa el riesgo crediticio con una clasificación binaria (\(f: \mathbb{R}^d \to \{+,-\}\)) y lo resume en una tarjeta de puntos (scorecard) según el riesgo que el cliente representa en ciertas características. La \(f\) que se usa es la regresión logística.

    11.1 Regresión logística desde los momios

    Sea \(P(E) = p\) la probabilidad del evento (p. ej. incumplir) y \(q = 1 - p\). Los momios son \(p/q\). Las variables aportan linealmente al logaritmo de los momios:

    $$\ln\!\Big(\frac{p}{1-p}\Big) = \beta_0 + \sum_{i=1}^{n}\beta_i x_i \;\Rightarrow\; \frac{p}{1-p} = e^{\beta_0+\sum\beta_i x_i} \;\Rightarrow\; \frac{1}{p} = 1 + e^{-\beta_0-\sum\beta_i x_i} \;\Rightarrow\; P(E) = \frac{1}{1+e^{-\beta_0-\sum\beta_i x_i}}$$
    El último término es la sigmoide: convierte cualquier número real en una probabilidad entre 0 y 1.

    Discretas

    Se analizan frecuencias (normalización). Los nulos se consideran una categoría. La variable (p. ej. SEXO) es la característica; sus valores (Hombre, Mujer) son los atributos.

    11.3 WoE e IV

    $$\text{WoE}_i = \ln\!\left(\frac{\%\,\text{no evento}_i}{\%\,\text{evento}_i}\right) \qquad\qquad \text{IV} = \sum_i \big(\%\,\text{no evento}_i - \%\,\text{evento}_i\big)\cdot \text{WoE}_i$$
    Continuas: 1) discretizar, 2) contar eventos y no eventos por bin, 3) logaritmo natural del cociente. Discretas: se omite el paso 1. Ventaja del WoE: mide el poder predictivo.

# WoE_i = ln(%NoEvento_i / %Evento_i)      IV = Σ (%NoEvento_i - %Evento_i) * WoE_i
import numpy as np
import pandas as pd

rng = np.random.default_rng(1)
n = 5000
edad = rng.integers(18, 75, n)
ingreso = rng.lognormal(9.8, 0.6, n)
# Probabilidad de incumplimiento (evento = 1): mayor en jóvenes y en ingresos bajos
logit = 1.5 - 0.05 * edad - 0.00004 * ingreso
evento = (rng.random(n) < 1 / (1 + np.exp(-logit))).astype(int)

def tabla_woe(df, var, tgt="evento", bins=5):
    d = df[[var, tgt]].copy()
    d["bin"] = pd.qcut(d[var], q=bins)                       # 1) discretizar en cuantiles
    t = d.groupby("bin", observed=True)[tgt].agg(total="count", eventos="sum")
    t["no_eventos"] = t["total"] - t["eventos"]
    t["%evento"] = t["eventos"] / t["eventos"].sum()          # 2) distribución de eventos
    t["%no_evento"] = t["no_eventos"] / t["no_eventos"].sum()
    t["WoE"] = np.log(t["%no_evento"] / t["%evento"])         # 3) logaritmo natural
    t["IV_i"] = (t["%no_evento"] - t["%evento"]) * t["WoE"]
    return t, t["IV_i"].sum()

def poder(iv):
    return ("No ayuda" if iv < 0.02 else "Bajo" if iv < 0.1 else
            "Regular" if iv < 0.3 else "Fuerte" if iv < 0.5 else "Sobrepredictiva (¡sospechosa!)")

for var in ["edad", "ingreso"]:

    print(f"IV = {iv:.4f} -> poder predictivo: {poder(iv)}\n")

def iv_woe(d, var):
    t = d.groupby(var, observed=True)[tgt].agg(total="count", eventos="sum")
    t["no_eventos"] = t["total"] - t["eventos"]
    pe, pn = t["eventos"] / t["eventos"].sum(), t["no_eventos"] / t["no_eventos"].sum()
    woe = np.log(pn / pe)                           # WoE = ln(%no evento / %evento)
    return float(((pn - pe) * woe).sum()), woe

    11.5 Scorecard y puntuaciones

    Ventajas de la tarjeta de puntos: fácil interpretación, explicable al usuario final, consistencia, reconocimiento de patrones, ajustable a las necesidades y útil para la toma de decisiones. Ejemplo de la clase: "Pablito, 28 años, gana $26,500, …, vive en Monterrey" suma 15 (edad) + 42 (ingreso) + … + 33 (ciudad) = 350 puntos.

    La escala es arbitraria (depende del analista y del negocio) y se fija con base en los momios del portafolio:

    $$\text{Factor} = \frac{\text{PDO}}{\ln 2} \qquad \text{Offset} = \text{Score} - \text{Factor}\cdot\ln(\text{odds}) \qquad \text{Puntos}_{\text{atributo}} = \Big(-\text{WoE}\cdot\beta + \frac{\alpha}{n}\Big)\cdot\text{Factor} + \frac{\text{Offset}}{n}$$
    PDO (Points to Double the Odds): cuántos puntos hacen que los momios bueno:malo se dupliquen; afecta la escala. Score: punto para fijar los odds de referencia. \(n\) = número de variables. El Offset desplaza la distribución de scores y el Factor la estira o encoge.
    ⚠️ Signo del intercepto

    La diapositiva escribe \(+\alpha/n\). Si tu logística modela P(malo) (evento = 1, como en sklearn) y el score debe crecer con los momios bueno:malo, el término correcto es \(-\alpha/n\): ambos sumandos llevan el signo invertido porque \(\ln(\text{bueno}/\text{malo}) = -(\alpha + \sum\beta\,\text{WoE})\). El programa usa esa versión y comprueba que el score total = Offset + Factor·ln(momios).

    # Módulo 1 · De la regresión logística a la tarjeta de puntos (scorecard)
# Factor = PDO / ln(2)        Offset = Score - Factor * ln(odds)
# Score total = Offset + Factor * ln(momios bueno:malo)
# Repartido entre las n variables (logística que modela P(malo) con variables WoE):
#   Puntos = (-WoE * beta - alpha / n) * Factor + Offset / n
import numpy as np

PDO = 20            # Points to Double the Odds: cada 20 puntos los momios bueno:malo se duplican
SCORE_REF = 600     # score de referencia...
ODDS_REF = 50       # ...que corresponde a momios 50:1 (50 buenos por cada malo)

factor = PDO / np.log(2)
offset = SCORE_REF - factor * np.log(ODDS_REF)
print(f"Factor = {PDO}/ln(2) = {factor:.4f}")
print(f"Offset = {SCORE_REF} - {factor:.4f}*ln({ODDS_REF}) = {offset:.4f}\n")

# Supongamos que la regresión logística (evento = malo, entrenada con variables WoE) dio:
alpha = -1.39                                   # intercepto ≈ ln(20% malos / 80% buenos)
betas = {"edad": -0.95, "ingreso": -0.80}       # negativos: más WoE (más "bueno") -> menos riesgo
n = len(betas)
woe = {"edad":    {"<25": -0.60, "25-30": -0.10, ">=30": 0.45},
       "ingreso": {"<10k": -0.70, "10k-25k": 0.05, ">=25k": 0.65}}

def puntos(var, atributo):
    return (-woe[var][atributo] * betas[var] - alpha / n) * factor + offset / n

print("SCORECARD")
for var, mapa in woe.items():
    for atributo, w in mapa.items():
        print(f"  {var:<8} {atributo:<8} WoE={w:>5.2f}  ->  {round(puntos(var, atributo)):>4} puntos")

# Calificar a un cliente: 28 años, ingreso 26,500
cliente = {"edad": "25-30", "ingreso": ">=25k"}
score = sum(puntos(v, a) for v, a in cliente.items())
print(f"\nCliente {cliente} -> score = {score:.1f}")

# Comprobación: el score es Offset + Factor * ln(momios bueno:malo del cliente)
logit_malo = alpha + sum(betas[v] * woe[v][a] for v, a in cliente.items())
p_malo = 1 / (1 + np.exp(-logit_malo))
print(f"P(malo) = {p_malo:.4f} | momios bueno:malo = {np.exp(-logit_malo):.2f}"
      f" | Offset + Factor*ln(momios) = {offset + factor * (-logit_malo):.1f}")
print(f"+{PDO} puntos (PDO) => momios x2: {np.exp((score + PDO - offset) / factor):.2f}")

    12.1 Cómo leer los coeficientes de la logística

    En la logística los coeficientes no se leen como en la regresión lineal. Como el modelo es lineal en el logaritmo de los momios, subir una unidad en \(x_i\) suma \(\beta_i\) al logit y, por lo tanto, multiplica los momios por \(e^{\beta_i}\). import pandas as pd

rng = np.random.default_rng(3)
fechas = pd.date_range("2021-01-01", "2021-12-31 23:00", freq="h")

oltp = pd.DataFrame([(e, f) for e in estaciones for f in fechas], columns=["id_station", "date"])
hora, mes = oltp["date"].dt.hour, oltp["date"].dt.month
diurno = 30 * np.sin((hora - 9) / 24 * 2 * np.pi).clip(0)       # pico de ozono al mediodía
temporada = 12 * np.exp(-((mes - 4.5) ** 2) / 4)                 # temporada alta: mar-may
por_zona = oltp["id_station"].map({"ACO": -4, "MER": 0, "UIZ": 5})
oltp["O3"] = (18 + diurno + temporada + por_zona + rng.normal(0, 5, len(oltp))).round(1)
