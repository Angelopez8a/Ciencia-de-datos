    1. ¿Qué es la modelación supervisada?

    Consiste en establecer una regla de mapeo entre las características \(X\) y una salida \(y\), con el fin de predecir \(y\) en datos nuevos que el modelo no ha visto. El modelo se entrena con un conjunto de pares:

    $$S_n = \big((X_1,y_1), (X_2,y_2), \dots, (X_n,y_n)\big) \in (\mathcal{X}\times\mathcal{Y})^n \qquad f: \mathcal{X} \to \mathcal{Y}$$
    \(X\) puede pertenecer a \(\mathbb{R}^m\) (variables continuas), a \(D^m\) (discretas) o a un espacio mixto, y el tipo de \(y\) define la tarea. Durante el entrenamiento, el algoritmo se evalúa de forma iterativa con una función de pérdida (el costo de equivocarse) y busca minimizarla.
    Regresión (\(y\) continua)

    Por ejemplo, proyecciones de ventas, precios, demanda, saldos o gastos. Algoritmos: regresión lineal, red elástica y LASSO, entre otros.

    Clasificación (\(y\) categórica)

    Por ejemplo, scores crediticios, abandono de clientes (fuga), detección de fraude o respuesta a campañas de marketing. Algoritmos: clasificadores lineales, SVM, árboles y KNN, entre otros.

    2. Regresión lineal

    $$y = \beta_0 + \beta_1 x_1 + \dots + \beta_n x_n + \varepsilon \qquad\qquad \text{estatura} = \beta_0 + \beta_1\cdot\text{padre} + \beta_2\cdot\text{madre} + \beta_3\cdot\text{hombre} + \varepsilon$$
    \(\varepsilon\) es un error con media 0 y varianza \(\sigma^2\), no correlacionado. Así, \(E(y\mid X) = \beta_0 + \beta_1 X\) y \(\operatorname{Var}(y\mid X) = \sigma^2\). \(\beta_1\) es el cambio en la media de \(y\) cuando \(X\) aumenta una unidad, y \(\beta_0\) es la media de \(y\) cuando \(X = 0\). La segunda ecuación es el modelo que se ajusta más abajo con los datos de Galton.

    2.1 Estimación por mínimos cuadrados (MCO)

    Se buscan los valores de \(\beta\) que minimizan la suma de los residuales al cuadrado. Al derivar e igualar a cero se obtiene:

    $$S(\beta_0,\beta_1) = \sum_{i=1}^{n}(y_i - \beta_0 - \beta_1 x_i)^2 \;\Rightarrow\; \hat\beta_1 = \frac{\operatorname{Cov}(X,y)}{\operatorname{Var}(X)},\qquad \hat\beta_0 = \bar y - \hat\beta_1 \bar x$$
    Los residuales \(\varepsilon_i = y_i - \hat y_i\) describen el comportamiento del error y son la base para validar los supuestos.

    El ejemplo usa los datos con los que Francis Galton describió en 1886 la «regresión hacia la media»: las estaturas de 934 hijos e hijas de 205 familias y las de sus padres. El programa estima la recta con las fórmulas cerradas, verifica el resultado con scikit-learn y después ajusta un modelo múltiple.

    # Módulo 2 · Mínimos cuadrados ordinarios (MCO) "a mano" vs scikit-learn
# Datos reales: estaturas de 934 hijos y de sus padres en 205 familias, registradas por Francis Galton (1886).
# Con estos datos Galton describió la "regresión hacia la media", el fenómeno que dio nombre a la técnica.
from pathlib import Path
import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression

ARCHIVO = Path(__file__).resolve().parents[1] / "datos" / "galton_familias.csv"
URL = "https://raw.githubusercontent.com/vincentarelbundock/Rdatasets/master/csv/HistData/GaltonFamilies.csv"
g = pd.read_csv(ARCHIVO if ARCHIVO.exists() else URL, index_col=0)
CM = 2.54                                        # las estaturas vienen en pulgadas
X = (g["midparentHeight"] * CM).to_numpy()       # estatura promedio de los padres (Galton multiplicó la de la madre por 1.08)
y = (g["childHeight"] * CM).to_numpy()           # estatura del hijo o de la hija

# Fórmulas cerradas: β1 = Cov(X, y) / Var(X),  β0 = ȳ − β1·x̄
b1 = np.sum((X - X.mean()) * (y - y.mean())) / np.sum((X - X.mean()) ** 2)
b0 = y.mean() - b1 * X.mean()
print(f"A mano  : β0 = {b0:.4f}, β1 = {b1:.4f}")

lr = LinearRegression().fit(X.reshape(-1, 1), y)
print(f"sklearn : β0 = {lr.intercept_:.4f}, β1 = {lr.coef_[0]:.4f}")

residuales = y - (b0 + b1 * X)
print("Suma de residuales:", round(float(residuales.sum()), 6) + 0.0, "| primeros 5:", residuales[:5].round(2))
print(f"Interpretación: por cada centímetro adicional en la estatura promedio de los padres, "
      f"la del hijo aumenta {b1:.3f} cm en promedio")

# Regresión hacia la media: padres 10 cm más altos que el promedio tienen hijos solo ~6 cm más altos
print(f"Padres 10 cm sobre la media ({X.mean() + 10:.1f} cm) -> hijo esperado {b0 + b1 * (X.mean() + 10):.1f} cm, "
      f"es decir, {b1 * 10:.1f} cm sobre la media de los hijos ({y.mean():.1f} cm)")

# Regresión múltiple: estatura = β0 + β1·padre + β2·madre + β3·hombre
Xm = np.c_[g["father"] * CM, g["mother"] * CM, (g["gender"] == "male").astype(int)]
m = LinearRegression().fit(Xm, y)
print(f"\nMúltiple: estatura = {m.intercept_:.2f} {m.coef_[0]:+.3f}·padre {m.coef_[1]:+.3f}·madre "
      f"{m.coef_[2]:+.2f}·hombre   (R² = {m.score(Xm, y):.3f})")

    Cómo leer la salida

    Las fórmulas cerradas y scikit-learn coinciden: \(\hat\beta_0 = 57.50\) y \(\hat\beta_1 = 0.637\). La suma de los residuales es 0, como ocurre siempre que el modelo incluye intercepto. Que la pendiente sea menor que 1 es justamente la regresión hacia la media que observó Galton: si los padres miden 10 cm más que el promedio, se espera que sus hijos midan solo 6.4 cm más que el promedio de los hijos. En el modelo múltiple, cada centímetro de estatura del padre suma 0.393 cm y cada centímetro de la madre, 0.318 cm; además, con los mismos padres, los hombres miden en promedio 13.25 cm más que las mujeres. Con estas tres variables se explica el 63.5 % de la varianza de la estatura (\(R^2 = 0.635\)).

# Linealidad (prueba RESET de Ramsey), homocedasticidad (Breusch-Pagan), independencia (Durbin-Watson)
# y normalidad de los residuales (Shapiro-Wilk). En las pruebas, p > 0.05 significa "no hay evidencia de falla".
from pathlib import Path
import numpy as np
import pandas as pd
import statsmodels.api as sm
from scipy import stats
from statsmodels.stats.diagnostic import het_breuschpagan, linear_reset
from statsmodels.stats.stattools import durbin_watson

DATOS = Path(__file__).resolve().parents[1] / "datos"
RD = "https://raw.githubusercontent.com/vincentarelbundock/Rdatasets/master/csv"
def leer(nombre, url, **kw):
    return pd.read_csv(DATOS / nombre if (DATOS / nombre).exists() else url, **kw)

def diagnostico(nombre, y, X):
    modelo = sm.OLS(np.asarray(y, float), sm.add_constant(np.asarray(X, float))).fit()
    r = modelo.resid
    p_reset = linear_reset(modelo, power=2, use_f=True).pvalue
    _, p_bp, _, _ = het_breuschpagan(r, modelo.model.exog)
    _, p_sw = stats.shapiro(r)
    ok = lambda p: "OK" if p > 0.05 else "FALLA"
    print(f"{nombre} (n = {int(modelo.nobs)}, R² = {modelo.rsquared:.3f})")
    print(f"  Linealidad RESET p = {p_reset:.4f} {ok(p_reset):<5} | Homocedasticidad BP p = {p_bp:.4f} {ok(p_bp)}")
    print(f"  Independencia DW = {durbin_watson(r):.3f} (≈ 2 sin autocorrelación) | Normalidad SW p = {p_sw:.4f} {ok(p_sw)}")

    3. Regresión logística

    También se le llama regresión logit y estima la probabilidad de que ocurra un evento. Aplica la transformación logit a los momios, es decir, al cociente entre la probabilidad del evento y la probabilidad de que no ocurra:

    $$\ln\!\Big(\frac{p}{1-p}\Big) = \beta_0 + \sum_{i=1}^{n}\beta_i X_i \qquad\Longleftrightarrow\qquad p = \frac{1}{1+e^{-(\beta_0+\sum\beta_i X_i)}}$$
    Las \(\beta\) se estiman por máxima verosimilitud: de manera iterativa se buscan los parámetros que maximizan la log-verosimilitud (o minimizan su negativo). Si \(p \ge 0.5\), se predice el evento. El ajuste se evalúa con métricas y con la prueba de Hosmer–Lemeshow. La regresión logística puede ser binaria, multinomial u ordinal.

    Un caso real muy citado es el del transbordador espacial Challenger. La noche del 27 de enero de 1986, ingenieros de Morton Thiokol, la empresa que fabricaba los cohetes impulsores, y directivos de la NASA discutieron si el frío podía dañar las juntas tóricas (O-rings) que sellan las uniones de esos cohetes. El pronóstico para la hora del despegue era de 31 °F (−0.6 °C), muy por debajo de la temperatura de cualquier lanzamiento anterior. El Challenger despegó a la mañana siguiente, con 36 °F (2 °C) según la Comisión Rogers, y se desintegró 73 segundos después por la falla de una de esas juntas. El programa ajusta una regresión logística con los 23 vuelos previos, en la línea del análisis que publicaron Dalal, Fowlkes y Hoadley (1989).

    # Módulo 2 · Regresión logística: momios, logit y probabilidad
# Datos reales: los 23 vuelos del transbordador espacial anteriores al accidente del Challenger
# (28 de enero de 1986), con la temperatura al despegar (°F) y cuántas de las seis juntas tóricas
# (O-rings) de los cohetes resultaron dañadas. La noche anterior al lanzamiento se discutió si el frío
# aumentaba el riesgo; el pronóstico para la hora del despegue era de 31 °F (−0.6 °C).
from pathlib import Path
import numpy as np
import pandas as pd
from sklearn.linear_model import LogisticRegression

ARCHIVO = Path(__file__).resolve().parents[1] / "datos" / "challenger_juntas.csv"
URL = "https://raw.githubusercontent.com/vincentarelbundock/Rdatasets/master/csv/openintro/orings.csv"
d = pd.read_csv(ARCHIVO if ARCHIVO.exists() else URL)
d["falla"] = (d["damaged"] > 0).astype(int)        # 1 = al menos una junta dañada en ese vuelo
celsius = lambda f: (f - 32) / 1.8

print(f"Vuelos: {len(d)} | con daño: {d['falla'].sum()} | temperaturas de {d['temperature'].min()} a "
      f"{d['temperature'].max()} °F")
print("Temperaturas de los vuelos con daño:", sorted(d.loc[d["falla"] == 1, "temperature"].tolist()))

X, y = d[["temperature"]], d["falla"]
modelo = LogisticRegression(C=1e6, max_iter=1000).fit(X, y)   # C grande ≈ sin regularización
b0, b1 = modelo.intercept_[0], modelo.coef_[0, 0]
print(f"\nln(p/(1-p)) = {b0:.4f} {b1:+.4f}·temperatura")
print(f"Factor de momios por cada grado Fahrenheit adicional: e^({b1:.4f}) = {np.exp(b1):.3f}")
print(f"Factor de momios por cada 10 °F MENOS: e^({-10 * b1:.3f}) = {np.exp(-10 * b1):.1f}")

for t in [75, 65, 53, 31]:
    logit = b0 + b1 * t
    p = 1 / (1 + np.exp(-logit))                    # sigmoide
    print(f"  {t} °F ({celsius(t):5.1f} °C) -> logit = {logit:6.3f}, momios = {np.exp(logit):9.3f}, "
          f"P(daño) = {p:.4f} -> clase {int(p >= 0.5)}")

sin_dano, dano = modelo.predict_proba(pd.DataFrame({"temperature": [31]}))[0]
print(f"predict_proba de sklearn a 31 °F: P(sin daño) = {sin_dano:.4f}, P(daño) = {dano:.4f}")
print(f"Frontera de decisión (p = 0.5): {-b0 / b1:.1f} °F ({celsius(-b0 / b1):.1f} °C)")

    Cómo leer la salida

    Siete de los 23 vuelos tuvieron daño, y los cuatro más fríos (de 53 a 63 °F) lo tuvieron todos. En la regresión logística, \(e^{\beta}\) es el factor de momios: aquí \(e^{-0.2322} = 0.793\), así que cada grado Fahrenheit adicional multiplica los momios de daño por 0.793; dicho al revés, 10 °F menos los multiplican por 10.2. Los coeficientes no se leen directamente como cambios en la probabilidad: al pasar de 75 a 65 °F, la probabilidad sube de 0.086 a 0.488, mientras que de 53 a 31 °F solo puede pasar de 0.939 a 0.9996. La frontera de decisión (\(p = 0.5\)) está en 64.8 °F (18.2 °C).

    Cuidado al extrapolar

    Ningún vuelo previo se había lanzado por debajo de 53 °F, así que 31 °F queda 22 grados fuera del rango observado: la cifra exacta de 0.9996 depende de suponer que la curva logística sigue siendo válida ahí. Lo que sí muestran los datos, sin ningún modelo, es que todos los vuelos por debajo de 65 °F tuvieron daño. En el análisis previo al lanzamiento se revisaron solo los vuelos que habían tenido daño (Comisión Rogers, 1986; Tufte, 1997); sin los vuelos sin daño, la relación con la temperatura no se aprecia. Incluir todos los casos, también aquellos en los que no pasó nada, es parte esencial del análisis.

    4. Regresiones penalizadas: LASSO, LARS, Ridge, Red Elástica y Bayesiana

    Cuando los coeficientes son inestables (por ejemplo, con pocos datos o con variables correlacionadas), se penaliza su tamaño en la función de costo:

    $$\text{LASSO (L1):}\ \ \sum_i (y_i - \hat y_i)^2 + \alpha\sum_j |\beta_j| \qquad\quad \text{Ridge (L2):}\ \ \sum_i (y_i - \hat y_i)^2 + \alpha\sum_j \beta_j^2$$ $$\text{ElasticNet:}\ \ \text{Loss} + \lambda\big(\alpha\,L_1 + (1-\alpha)\,L_2\big),\qquad \alpha\in[0,1]$$
    En las diapositivas, el término de error aparece como \(\sum(y_i-\hat y_i)\), sin el cuadrado; se trata del error cuadrático, como en MCO. En scikit-learn, \(\alpha\) controla la fuerza total de la penalización y l1_ratio, la mezcla entre L1 y L2 (en la regresión logística, el parámetro equivalente es \(C = 1/\alpha\)).

    5. Gradiente descendente (y su versión estocástica)

    El gradiente es la pendiente o inclinación de una superficie, y la idea del método es descender por ella hasta el punto más bajo. El documento del módulo usa la función \(y = x^2 - 2x - 3\), cuyo mínimo está en \(x = 1\) (\(y = -4\)): partiendo de \(x = 3\), se desciende por la curva. El método es útil cuando no es posible despejar analíticamente el punto donde la derivada vale 0.

    1. Calcular el gradiente \(\nabla f = (\partial f/\partial x_1, \dots, \partial f/\partial x_n)\).
    2. Elegir un valor inicial aleatorio de los parámetros.
    3. Evaluar la función en esos parámetros.
    4. Tamaño del paso = gradiente × tasa de aprendizaje (\(\gamma = \nabla f\cdot\alpha\)).
    5. Nuevos parámetros = parámetros − tamaño del paso.
    6. Repetir 3–5 hasta que el gradiente ≈ 0 (o menor que un error aceptado).

    Se recomiendan tasas pequeñas (0.05, 0.03 o 0.01). El costo crece rápido: con 30,000 observaciones y 8 variables se necesitan 240,000 cálculos por iteración, y con 1,000 iteraciones, 240 millones. Hay dos alternativas:

    • Gradiente descendente estocástico (SGD): estima el gradiente con observaciones elegidas al azar; en su forma pura, con una sola observación en cada paso.
    • Mini-batch SGD: usa un lote pequeño de observaciones en cada paso, lo que equilibra la estabilidad del GD con la velocidad del SGD.

    Con α = 0.1 el descenso es gradual; con α = 0.5 se llega al mínimo en un paso, y con α = 0.9 el valor oscila alrededor del mínimo antes de converger.

    return x, max_iter

    6. Análisis discriminante (LDA y QDA)

    Es un método sencillo, robusto e interpretable. Se usa como modelo base antes de probar clasificadores más complejos, y también para reducir dimensiones. Divide el espacio en \(k\) regiones sin intersección, y cada observación \(x_i\) se asigna a la clase de la región en la que cae. Hay dos reglas de asignación:

    • Máxima verosimilitud (cuando todas las clases tienen la misma probabilidad): \(j = \arg\max_k f_k(x_i)\).
    • Criterio bayesiano (con probabilidades a priori \(\pi_k\)): \(j = \arg\max_k \pi_k f_k(x_i)\).
    $$\delta_j(x) = \log f_j(x) + \log \pi_j \qquad\text{(función discriminante)}$$ $$\text{LDA (covarianza común):}\ \ \delta_k(X) = X^T\Sigma^{-1}\mu_k - \tfrac12\mu_k^T\Sigma^{-1}\mu_k + \log\pi_k \quad\text{(lineal en } X)$$ $$\text{QDA (covarianza por clase):}\ \ \delta_k(X) = -\tfrac12\log|\Sigma_k| - \tfrac12(X-\mu_k)^T\Sigma_k^{-1}(X-\mu_k) + \log\pi_k$$

    7. Truco del kernel y regresión de cresta kernel

    Si las clases no pueden separarse con una recta, los datos se proyectan a una dimensión mayor donde sí sean separables. Calcular explícitamente esa proyección \(\phi\) es muy costoso; el truco del kernel obtiene el producto interno en el espacio grande operando solo en el espacio original:

    $$k(x,y) = (x^T y)^2 = \Big(\sum_{i=1}^3 x_i y_i\Big)^2 = \sum_{i,j=1}^{3} x_i x_j\, y_i y_j = \phi(x)^T\phi(y)\quad\text{con }\phi\in\mathbb{R}^9$$
    Los kernels más comunes son el polinómico y el RBF (gaussiano). La regresión de cresta kernel resuelve \(\hat y = y(K+\lambda I_n)^{-1}k(X)\), por lo que solo necesita la matriz de kernel \(K\).

    8. Máquinas de vector soporte (SVM)

    Buscan el hiperplano que separa las clases con el máximo margen. Un hiperplano es un punto en \(\mathbb{R}\), una recta en \(\mathbb{R}^2\) y un plano o hipersuperficie en \(\mathbb{R}^n\) con \(n\ge3\). Los vectores soporte son las observaciones más cercanas al hiperplano: determinan su posición y orientación, y su distancia a él es el margen.

    $$c(x,y,f(x)) = \big(1 - y\cdot f(x)\big)_+ \qquad\qquad \min_w\ \lambda\lVert w\rVert^2 + \sum_{i=1}^{n}\big(1 - y_i\langle x_i, w\rangle\big)_+$$
    La pérdida de bisagra (hinge loss) vale 0 cuando el signo es correcto y \(y\cdot f(x) \ge 1\). Regla de actualización: si la observación está bien clasificada y fuera del margen, \(w \leftarrow w - \alpha(2\lambda w)\); en caso contrario, \(w \leftarrow w + \alpha(y_i x_i - 2\lambda w)\).

    9. K vecinos más cercanos (KNN)

    Es conocido por su sencillez: es un algoritmo perezoso (no «entrena», solo guarda los datos), consta de tres pasos y tiene una efectividad media. Asigna de forma «dura» la clase mayoritaria entre los \(k\) vecinos más cercanos:

    1. Calcular las distancias de \(x_0\) a todas las observaciones: \(d(x_0, x_i)\ \forall x_i\in X\).
    2. Ordenarlas de menor a mayor y tomar las \(k\) más cercanas.
    3. Asignar la clase mayoritaria entre esos \(k\).
    $$d_{\text{Manhattan}} = \sum_i |a_i-b_i| \qquad d_{\text{Euclidiana}} = \sqrt{\sum_i (a_i-b_i)^2} \qquad d_{\text{Minkowski}} = \Big(\sum_i |a_i-b_i|^p\Big)^{1/p}$$
    Su desempeño depende de la métrica, de la escala de las variables (conviene estandarizarlas), de las características que se usen y del valor de \(k\).

    10. Bayes ingenuo

    Es un ejemplo del principio KIS (Keep It Simple): un modelo más simple es más fácil de entender y más rápido. Se usa mucho en procesamiento de lenguaje natural (NLP) y se basa en el teorema de Bayes:

    $$P(A\mid B) = \frac{P(B\mid A)\,P(A)}{P(B)} \qquad\Rightarrow\qquad P(y\mid x_1,\dots,x_n) \propto P(y)\prod_{i=1}^{n}P(x_i\mid y),\qquad \hat y = \arg\max_y P(y)\prod_i P(x_i\mid y)$$
    Sus supuestos «ingenuos» son la independencia (ninguna característica depende de otra; por ejemplo, el color no depende del origen) y el equi-impacto (todas las características aportan lo mismo). El denominador se omite porque es igual para todas las clases.

def naive_bayes(datos, objetivo, nuevo, laplace=0):
    """Calcula P(y) · Π P(x_i | y) para cada clase y devuelve la clase con el producto mayor."""
    print("    clase: P(y) · " + " · ".join(f"P({valor} | y)" for valor in nuevo.values()))
    resultados = {}
    for clase, grupo in datos.groupby(objetivo):
        factores = [len(grupo) / len(datos)]          # P(y), probabilidad a priori
        for var, valor in nuevo.items():
            k = datos[var].nunique()
            factores.append(((grupo[var] == valor).sum() + laplace) / (len(grupo) + laplace * k))
        resultados[clase] = float(np.prod(factores))  # supuesto ingenuo: características independientes
        print(f"    {clase:>5}: " + " · ".join(f"{f:.3f}" for f in factores) + f" = {resultados[clase]:.5f}")
    total = sum(resultados.values())
    print("    Al normalizar:", {c: round(v / total, 3) for c, v in resultados.items()})
    return max(resultados, key=resultados.get)

    11. Árboles de decisión

    Un árbol es un conjunto de reglas lógicas que parten de una raíz y llegan a conclusiones particulares, llamadas hojas; se dibuja «de cabeza», con la raíz arriba. La figura muestra un ejemplo clásico ajustado con los datos de 1,309 pasajeros del Titanic, que usa el sexo, la edad y el número de hermanos o cónyuges a bordo (sibsp). En cada hoja aparece el porcentaje de pasajeros de ese grupo que sobrevivió.

    11.1 Cortes binarios recursivos y costo

    1. Se proponen \(n\) candidatos de partición (uno por cada característica y punto de corte).
    2. Se calcula la información ganada de cada candidato.
    3. Se elige el que minimiza el costo y maximiza la ganancia.
    4. Se repite de forma recursiva en cada rama hasta alcanzar la pureza deseada (es un algoritmo codicioso).
    $$\text{Regresión: } \text{MSE} = \frac1n\sum(y_i-\hat y_i)^2,\ \ \text{MAE} = \frac1n\sum|y_i-\hat y_i| \qquad \text{Clasificación: } \text{Gini} = \sum_k p_k(1-p_k),\ \ \text{Entropía} = -\sum_k p_k\log p_k$$
    Gini = 0 indica un nodo puro (todas las observaciones son de la misma clase); en un problema binario, Gini = 0.5 corresponde a una mezcla 50/50, es decir, a una partición que no separa nada.

    11.2 ¿Cuándo detenerse? y poda

    Buscar la pureza total es costoso y provoca sobreajuste. Los criterios de paro habituales son un mínimo de observaciones por hoja, una profundidad máxima y un nivel de pureza. La poda recorre el árbol de las hojas a la raíz y elimina los nodos que no son significativos según el costo (poda por reducción de costo), lo que reduce la complejidad y el sobreajuste.

    12. Redes neuronales (introducción)

    Están inspiradas en el cerebro y tienen tres componentes: la neurona (cada una es un modelo simple, una función lineal), la función de activación (transforma la salida, incorpora la no linealidad y decide si la neurona «se activa») y las capas (de entrada, ocultas y de salida). La pregunta que las motiva en el curso es: «si podíamos crear una regresión lineal con gran efectividad, ¿qué pasaría si creamos varias?». Sin funciones de activación, una red de una capa equivale a una regresión lineal.

    $$Z_k = \sum_{i=1}^{j} x_i w_{ik} + w_{0k} \;\to\; f(Z_k) \;\to\; Z = \sum_{t=1}^{m} f(Z_t)\,v_t + v_0 \qquad J(\theta) = \frac1n\sum_{i=1}^{n}\text{Loss}\big(y^{(i)}F(x^{(i)};\theta)\big)$$
    Activaciones vistas: escalón (indicadora), sigmoide (en la salida de los clasificadores), tanh (de −1 a 1, preferida en las capas ocultas) y ReLU (de 0 a ∞, de cálculo barato). Pérdidas: bisagra, log loss y MSE (más la penalización \(\tfrac12\lVert\theta\rVert^2\)). Optimizadores: GD y sus variantes, momentum, Adagrad, AdaDelta y Adam. El entrenamiento repite el ciclo propagación hacia adelante → costo → propagación hacia atrás, normalmente con GPU o TPU.

    14. Métricas y selección del modelo campeón

    Los datos se dividen en un conjunto de entrenamiento y uno de prueba; el de prueba no interviene en el ajuste y se usa solo al final. Así se detecta el sobreajuste (overfitting): un modelo excelente en entrenamiento, pero deficiente con datos nuevos. Además del desempeño, el modelo campeón debe responder a las necesidades del negocio; por ejemplo, puede requerirse que sea interpretable. El programa de esta sección evalúa dos modelos con datos reales: la estatura en las familias de Galton (regresión) y el abandono de clientes de la telefónica de IBM (clasificación).

    14.1 Regresión

    Cuando \(y\) es continua, acertar el valor exacto es prácticamente imposible, así que se busca acercarse lo más posible. Lo ideal es que los residuales se comporten como una normal centrada en 0.

    $$\text{MaxError} = \max_i|y_i-\hat y_i|\quad \text{MAE} = \frac1n\sum|y_i-\hat y_i|\quad \text{MSE} = \frac1n\sum(y_i-\hat y_i)^2\quad \text{MedAE} = \operatorname{mediana}|y_i-\hat y_i|$$ $$R^2 = 1 - \frac{SS_{res}}{SS_{tot}} = 1 - \frac{\sum(y_i-\hat y_i)^2}{\sum(y_i-\bar y)^2}$$
    Se busca que el MAE sea menor que la desviación estándar de \(y\). El MSE castiga más los errores grandes, y \(R^2\) es la proporción de la varianza explicada.

    14.2 Clasificación: matriz de confusión

    $$\text{Accuracy} = \frac{TP+TN}{TP+TN+FP+FN}\qquad \text{Precision} = \frac{TP}{TP+FP}\qquad \text{Recall} = \frac{TP}{TP+FN}$$ $$F1 = 2\,\frac{\text{precision}\cdot\text{recall}}{\text{precision}+\text{recall}}\qquad \text{Balanced acc.} = \frac1k\sum_k \text{Recall}_k \qquad \text{Especificidad} = \frac{TN}{TN+FP}$$
    PrecisiónDe los casos que el modelo marcó como evento, ¿cuántos lo eran? Disminuye con los falsos positivos.
    Recall / sensibilidadDe los eventos reales, ¿cuántos detectó? Disminuye con los falsos negativos.
    F1Media armónica de la precisión y el recall.
    Balanced accuracyPromedio del recall de cada clase; es útil cuando las clases están desbalanceadas.

    14.3 Curva ROC, AUC, Gini, KS y Lift

    La curva ROC grafica la tasa de verdaderos positivos (TPR, que es el recall o sensibilidad) contra la tasa de falsos positivos (FPR = 1 − especificidad) para todos los cortes de probabilidad. El área bajo la curva (AUC o estadístico C) resume el desempeño: 0.5 equivale al azar y 1, a un modelo perfecto. El Gini se calcula como 2·AUC − 1. El KS es la máxima separación entre las distribuciones acumuladas de los eventos y de los no eventos. El Lift compara la tasa de eventos que logra el modelo en un grupo con la tasa natural: si el 10 % con mayor score tiene una tasa de 0.8 y la tasa natural es 0.2, el lift es 0.8/0.2 = 4.

    15. Monitoreo: reportes de estabilidad y desempeño

    Las poblaciones cambian con el tiempo y, además, poner un modelo en operación modifica el comportamiento de la población. Por eso se monitorean dos aspectos: la estabilidad poblacional (las variables del modelo) y el desempeño (su poder predictivo).

    • Distribución de las características: comparar los histogramas de dos periodos, con apoyo de contrastes de hipótesis.
    • Reporte de características: en variables categóricas (o continuas discretizadas), comparar las frecuencias esperadas con las actuales mediante el índice de desviación o PSI.
    $$\text{PSI} = \sum_{k\,\in\,\text{categorías}} (\%\text{Actual}_k - \%\text{Esperado}_k)\times\ln\!\Big(\frac{\%\text{Actual}_k}{\%\text{Esperado}_k}\Big)$$
    < 0.1: cambio insignificante · 0.1 – 0.25: cambio menor · > 0.25: cambio mayor; conviene reparametrizar o recalibrar el modelo.
