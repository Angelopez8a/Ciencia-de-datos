    2. Reducción de dimensiones con PCA (paso a paso)

    PCA busca nuevas variables (componentes principales) que son combinaciones lineales de las originales, ortogonales entre sí y ordenadas por la varianza que explican. El algoritmo:

    1. Estandarizar (o al menos centrar) las variables.
    2. Calcular la matriz de covarianza \(C = \frac{1}{n-1}X_c^T X_c\).
    3. Obtener eigenvalores \(\lambda_k\) y eigenvectores \(v_k\) de \(C\): cada eigenvector es una dirección (componente) y su eigenvalor la varianza en esa dirección.
    4. Ordenar de mayor a menor \(\lambda\) y quedarse con las \(k\) primeras.
    5. Proyectar: \(Z = X_c V_k\).
    $$\text{Varianza explicada}_k = \frac{\lambda_k}{\sum_j \lambda_j}\qquad\qquad \text{¿Cuántas componentes? } \to \text{acumulada} \ge 80\text{–}90\%,\ \text{codo del scree plot, o } \lambda_k > 1 \text{ (Kaiser, datos estandarizados)}$$

    # Módulo 3 · PCA paso a paso: covarianza -> eigenvectores -> proyección (y comparación con sklearn)
import numpy as np
from sklearn.decomposition import PCA

np.set_printoptions(precision=4, suppress=True)
X = np.array([[2.5, 2.4], [0.5, 0.7], [2.2, 2.9], [1.9, 2.2], [3.1, 3.0],
              [2.3, 2.7], [2.0, 1.6], [1.0, 1.1], [1.5, 1.6], [1.1, 0.9]])

Xc = X - X.mean(axis=0)                      # 1) centrar (en la práctica: estandarizar)
C = np.cov(Xc, rowvar=False)                 # 2) matriz de covarianza
valores, vectores = np.linalg.eigh(C)        # 3) eigen-descomposición
orden = np.argsort(valores)[::-1]
valores, vectores = valores[orden], vectores[:, orden]
print("Matriz de covarianza:\n", C)
print("Eigenvalores (varianza de cada componente):", valores)
print("Proporción de varianza explicada:", valores / valores.sum())
Z = Xc @ vectores[:, :1]                     # 4) proyectar en la 1a componente
print("Datos proyectados en PC1:", Z.ravel())

pca = PCA(n_components=2).fit(X)
print("\nsklearn explained_variance_ratio_:", pca.explained_variance_ratio_)
print("sklearn PC1 (signo puede variar):", pca.transform(X)[:, 0])

    📝 Para la práctica
    • Loadings (pca.components_): el peso de cada variable original en cada componente; sirven para nombrar las componentes ("PC1 = tamaño", "PC2 = gasto vs frecuencia").
    • PCA es lineal y no supervisado: no sabe cuál variable importa para predecir, solo cuál varía más.
    • t-SNE (y UMAP) son no lineales: excelentes para visualizar clusters en 2D, no para alimentar modelos.

    3. K-means

    Agrupa en \(k\) clusters minimizando la distancia de cada punto al centroide (media) de su grupo.

    1. Elegir \(k\) y colocar \(k\) centroides iniciales (sklearn usa k-means++: centroides iniciales alejados entre sí).
    2. Asignar cada punto al centroide más cercano.
    3. Actualizar cada centroide como la media de sus puntos.
    4. Repetir 2–3 hasta que las asignaciones no cambien (n_init repite todo con varias semillas y se queda con la mejor).
    $$\text{Inercia (WCSS)} = \sum_{j=1}^{k}\sum_{x_i\in C_j}\lVert x_i - \mu_j\rVert^2 \qquad\qquad s(i) = \frac{b(i) - a(i)}{\max\{a(i), b(i)\}}$$
    \(a(i)\) = distancia promedio de \(i\) a su propio cluster; \(b(i)\) = distancia promedio al cluster vecino más cercano. Silueta cerca de 1: bien agrupado; cerca de 0: en la frontera; negativa: mal asignado. Davies-Bouldin: menor es mejor. Calinski-Harabasz: mayor es mejor.

    Método del codo

    La inercia siempre baja con más k; buscamos el "codo" donde deja de bajar mucho: k = 4.

    Coeficiente de silueta

    Máximo en k = 4 (0.802): confirma el codo.

from sklearn.datasets import make_blobs
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, davies_bouldin_score, calinski_harabasz_score

X, _ = make_blobs(n_samples=600, centers=4, cluster_std=1.0, random_state=7)
X = StandardScaler().fit_transform(X)

print(f"{'k':>2}{'Inercia (WCSS)':>16}{'Silueta':>10}{'Davies-B':>10}{'Calinski-H':>12}")
for k in range(2, 9):
    km = KMeans(n_clusters=k, n_init=10, random_state=0).fit(X)
    et = km.labels_

km = KMeans(n_clusters=4, n_init=10, random_state=0).fit(X)

print("Tamaño de cada cluster:", [int((km.labels_ == c).sum()) for c in range(4)])

    ⚠️ Limitaciones de K-means

    Hay que fijar \(k\); asume clusters esféricos y de tamaño parecido; es sensible a la escala, a los atípicos y a la inicialización; todo punto termina en algún cluster (no detecta ruido). Por eso existen el jerárquico y DBSCAN.

    4. Clustering jerárquico

    Construye una jerarquía de agrupaciones representada en un dendrograma. El más común es el aglomerativo (bottom-up): empieza con cada punto como su propio cluster y en cada paso une los dos clusters más cercanos hasta tener uno solo. (El divisivo hace lo contrario: top-down.)

    4.1 Criterios de enlace (linkage)

    EnlaceDistancia entre clusters A y BComportamiento
    Single (simple)mínima distancia entre un punto de A y uno de Bencadena; detecta formas alargadas; sensible al ruido
    Complete (completo)máxima distancia entre puntos de A y Bclusters compactos
    Average (promedio)promedio de todas las distancias entre paresintermedio
    Wardaumento de la varianza (WCSS) al unirlosclusters compactos de tamaño similar (el más usado)

    # Módulo 3 · Clustering jerárquico aglomerativo: matriz de enlace (linkage) y corte del dendrograma
import numpy as np
from scipy.cluster.hierarchy import linkage, fcluster
from sklearn.cluster import AgglomerativeClustering

puntos = np.array([[1, 1], [1.5, 1], [5, 5], [5, 5.5], [9, 1], [9, 1.8]])
nombres = ["A", "B", "C", "D", "E", "F"]

for metodo in ["single", "complete", "average", "ward"]:
    Z = linkage(puntos, method=metodo)
    print(f"Enlace '{metodo}':")
    for i, (a, b, dist, n) in enumerate(Z):
        print(f"  paso {i + 1}: une {int(a)} y {int(b)} a distancia {dist:.3f} -> nuevo grupo con {int(n)} puntos")

Z = linkage(puntos, method="ward")
etiquetas = fcluster(Z, t=3, criterion="maxclust")          # "cortar" el árbol en 3 grupos
print("\nCorte en 3 clusters (ward):", dict(zip(nombres, etiquetas.tolist())))

ac = AgglomerativeClustering(n_clusters=3, linkage="ward").fit(puntos)
print("sklearn AgglomerativeClustering:", dict(zip(nombres, ac.labels_.tolist())))

    💡 Ventajas y desventajas

    + No hay que fijar \(k\) de antemano (se decide al cortar el dendrograma); el dendrograma es muy interpretable. − Costoso en memoria y tiempo (\(O(n^2)\) distancias), no escala a millones de registros; una unión no se deshace. Los números de etiqueta son arbitrarios (sklearn y scipy los nombran distinto pero forman los mismos grupos).

    5. DBSCAN (clustering por densidad)

    Density-Based Spatial Clustering of Applications with Noise. Un cluster es una región densa de puntos separada por regiones poco densas. Dos parámetros:

    • eps (ε): radio de vecindad.
    • min_samples: número mínimo de puntos dentro del radio para considerar una región densa.
    Punto núcleo (core)Tiene al menos min_samples vecinos dentro de ε.
    Punto frontera (border)No es núcleo, pero está dentro del ε de un núcleo.
    Ruido (noise)Ni núcleo ni frontera: etiqueta −1. ¡DBSCAN detecta atípicos!

    El algoritmo toma un núcleo no visitado, crea un cluster y lo expande con todos los puntos alcanzables por densidad; repite hasta visitar todo. No hay que fijar \(k\) y encuentra formas arbitrarias.

    K-means vs DBSCAN en datos con forma de "lunas" (+3 atípicos)

    K-means corta las lunas con una recta (ARI = 0.475). DBSCAN (ε = 0.25, min_samples = 5) las recupera perfectamente (ARI = 1.000) y marca los 3 atípicos como ruido (gris).

    cluster 0cluster 1ruido (−1)

    5.1 ¿Cómo elegir ε? La gráfica de k-distancias

    Para cada punto se calcula la distancia a su k-ésimo vecino (k = min_samples), se ordenan de menor a mayor y se grafican. El codo (donde la curva sube bruscamente) sugiere ε: por debajo, los puntos están en zonas densas; por encima, son ruido.

    Distancia al 5.º vecino (ordenada)

    El codo aparece alrededor de 0.2–0.3; con ε = 0.25 se obtienen los 2 clusters correctos.

    # Módulo 3 · DBSCAN vs K-means en formas no esféricas (lunas) + elección de eps con k-distancias
import numpy as np
from sklearn.datasets import make_moons
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import DBSCAN, KMeans
from sklearn.neighbors import NearestNeighbors
from sklearn.metrics import adjusted_rand_score

X, y = make_moons(n_samples=400, noise=0.07, random_state=0)
X = np.vstack([X, [[2.5, 1.5], [-1.5, -0.8], [0.5, 1.6]]])      # 3 puntos atípicos
y = np.r_[y, [-1, -1, -1]]
X = StandardScaler().fit_transform(X)

# Gráfica de k-distancias: distancia al 5º vecino de cada punto (min_samples = 5)
dist, _ = NearestNeighbors(n_neighbors=5).fit(X).kneighbors(X)
k_dist = np.sort(dist[:, -1])
print("Percentiles de la 5-distancia (el 'codo' sugiere eps):",
      np.percentile(k_dist, [50, 90, 95, 99]).round(3))

for eps in [0.1, 0.25, 0.5]:
    db = DBSCAN(eps=eps, min_samples=5).fit(X)
    et = db.labels_
    n_cl = len(set(et)) - (1 if -1 in et else 0)
    print(f"eps={eps:<5} clusters={n_cl}  ruido={int((et == -1).sum()):>3}  "
          f"núcleo={len(db.core_sample_indices_):>3}  ARI vs real={adjusted_rand_score(y, et):.3f}")

km = KMeans(n_clusters=2, n_init=10, random_state=0).fit(X)
print(f"K-means k=2           ARI vs real={adjusted_rand_score(y, km.labels_):.3f}  (no sabe de ruido)")

    # Módulo 3 · Ciclo completo de clustering: preparar -> estandarizar -> reducir -> agrupar -> evaluar -> perfilar
import numpy as np
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

rng = np.random.default_rng(5)
def grupo(n, gasto, visitas, antig, desc):
    return pd.DataFrame({"gasto_mensual": rng.normal(gasto, gasto * 0.15, n),
                         "visitas_mes": rng.poisson(visitas, n),
                         "antiguedad_meses": rng.normal(antig, 6, n).clip(1),
                         "uso_descuentos": rng.beta(*desc, n)})
clientes = pd.concat([grupo(300, 800, 2, 40, (2, 8)), grupo(200, 3500, 8, 60, (2, 5)),
                      grupo(250, 1200, 12, 10, (8, 2))], ignore_index=True)
print("1) Datos:", clientes.shape)

X = StandardScaler().fit_transform(clientes)               # 2) misma escala
pca = PCA(n_components=0.9).fit(X)                          # 3) quedarnos con 90% de varianza
Xp = pca.transform(X)
print(f"3) PCA: {Xp.shape[1]} componentes explican {pca.explained_variance_ratio_.sum():.1%}")

sil = {k: silhouette_score(Xp, KMeans(k, n_init=10, random_state=0).fit_predict(Xp)) for k in range(2, 7)}
k = max(sil, key=sil.get)
print("4-5) Silueta por k:", {kk: round(v, 3) for kk, v in sil.items()}, "-> k elegido =", k)

clientes["segmento"] = KMeans(k, n_init=10, random_state=0).fit_predict(Xp)
perfil = clientes.groupby("segmento").agg(n=("gasto_mensual", "size"), gasto=("gasto_mensual", "mean"),
                                          visitas=("visitas_mes", "mean"),
                                          antiguedad=("antiguedad_meses", "mean"),
                                          descuentos=("uso_descuentos", "mean")).round(2)
print("6) Perfilamiento de segmentos (medias):\n", perfil.to_string())

    8. Preguntas de repaso

    ¿Por qué hay que estandarizar antes de PCA y de clustering?

    PCA se basa en la covarianza y el clustering en distancias: una variable con valores grandes dominaría la varianza/distancia aunque no sea la más importante. Estandarizar pone a todas en la misma escala.

    ¿Qué representa un eigenvalor en PCA?

    La varianza de los datos en la dirección de su eigenvector (componente). Dividido entre la suma de eigenvalores da la proporción de varianza explicada.

    ¿Por qué la inercia no sirve sola para elegir k?

    Porque siempre disminuye al aumentar k (con k = n vale 0). Se busca el codo, o se usa la silueta, que sí penaliza tener demasiados clusters.

    Diferencia entre punto núcleo, frontera y ruido en DBSCAN.

    Núcleo: tiene ≥ min_samples vecinos en ε. Frontera: no es núcleo pero cae en el ε de un núcleo. Ruido: ninguno de los dos; se etiqueta −1.

    ¿Qué hace el enlace de Ward?

    Une, en cada paso, el par de clusters cuyo merge aumenta lo menos posible la suma de cuadrados dentro de los clusters (varianza); produce grupos compactos y de tamaño similar.

    ¿Qué es el perfilamiento y por qué importa?

    Describir cada cluster con estadísticas de las variables originales (medias, proporciones) para interpretarlo y nombrarlo. Sin perfilamiento, los clusters no se traducen en acciones de negocio.
